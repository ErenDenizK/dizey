# Dizey

Dizey is a mobile-first linear algebra learning app (PWA). Its first target is the YTÜ MAT1320 Linear Algebra Midterm 1; its long-term scope is the whole of introductory linear algebra, taught for both exam performance and real understanding.

The app is in early development. Nothing here is user-facing yet.
