# Learning science for Dizey's teaching and feedback design

## Question

Which teaching flow and which feedback design best serve both exam success and real understanding, and should the
app show wrong-answer counts? Feeds decisions 0002 and 0003.

## Findings

- Novices learn more from worked examples than from unguided problem solving; the benefit reverses as expertise
  grows (expertise reversal), so guidance should fade.
- Retrieval practice beats rereading for retention; spacing it out helps further.
- Interleaving problem types improves the ability to choose a method, which is the core difficulty of a mixed exam.
- High-confidence errors, once corrected, are remembered better than low-confidence ones.
- Feedback raises performance on average, but in over a third of 607 effect sizes it lowered it; feedback that
  draws attention to the self rather than the task is the harmful kind.
- Grades alone can lower interest and later performance; task-related comments raise them.
- Task, process and self-regulation feedback works best; praise of the person works least.

## Taken

Worked examples with fading, spaced and interleaved retrieval, diagnostic distractors, an optional confidence tap,
task-level feedback without a running counter, honest scores in mock exams.

## Rejected

- Productive failure as the default lesson opening: it can deepen understanding but costs time; kept for a few key
  concepts only.
- Score-first or lives-based gamification: self-focused feedback.
